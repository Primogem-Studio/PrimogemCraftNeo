# Overview

This is the remake of [Primogem Craft](https://github.com/Primogem-Studio/PrimogemCraft). Its code structure and registry IDs have been rebuilt from scratch compared with the legacy version, so **this version is not compatible with the old Primogem Craft**.

REI and JEI integrations cover Wish drops, bidirectional Stellar Converter recipes and their costs, and Wish Core feeding materials with server-synchronized Wish Values. Both integrations use the same recipe data and translations. Recipe viewers are optional; install the NeoForge version for Minecraft 1.21.1 (JEI 19.19.0 or later in the 19.x series).

The development runtime loads both REI and JEI by default, including when using `runClient`. Both integrations are included in the built mod.

# The mod includes
* **Curios** — a variety of Curios from *Honkai: Star Rail*, plus original Curios.
* **Events** — a large number of random events and event cards that drop in-game, where the player has to make a choice.
* **Wishes** — a fairly complete Wish system inspired by *Genshin Impact*, used to obtain various esources and equipment.
* **Equipment**
    - Special weapon progression: refine and enhance Wish Weapons for powerful effects.
    - Functional tool-weapons crafted from Elemental Crystals, and armor upgrades with set bonuses.
* **Items** — fun items for entertainment and utility.
* **Blocks** — a variety of otherworld-style blocks for decoration.
* **Music Discs** — several HOYO-MiX tracks ported into the mod.
