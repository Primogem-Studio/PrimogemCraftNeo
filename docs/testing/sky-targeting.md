# Sky targeting

Build verification: `compileJava` and `build`. The checks below require a running game and have not been run automatically.

The client config `config/primogemcraft-client.toml` contains `[tacz]` with `sky_target_overlay = true` by default. Set it to `false` to hide the aiming decorations, target marker, distance, status and lock chime. Target locking, homing and bullet synchronization remain active. Verify both values, then re-enable the option while a target is locked and confirm the current marker returns.

1. Load PrimogemCraft with TACZ, obtain `pgfs:tiankong`, and aim in first person at a moving hostile mob within 64 blocks. Expect two compact cyan wing outlines mirrored on each side, open gold brackets, seven diamonds lighting symmetrically outward from the center, a contracting diamond target marker, and a gold ready state with one chime after eight server ticks. The marker must follow the mob with distance shown.
2. Fire after lock. Expect cyan trails and rounds that turn toward the moving target. Check headshots, penetration, and the existing random elemental damage and effects still work. Guidance must stop on the first entity hit so penetrating rounds continue forward without returning to hit the target again. Fire before lock and from the hip: expect the normal unguided rounds.
3. Move the target behind a solid wall, beyond 64 blocks, or more than 25 degrees away from the aim direction; kill it or change dimension. Expect the marker to clear. Bullets must collide with walls and stop guiding when visibility is lost. Already fired rounds may continue guiding after the shooter stops aiming.
4. Put a nearer second mob beside the target. Expect the acquired target to remain selected until it becomes invalid; acquisition requires the target within 12 degrees of the crosshair. Check allies, owned tame animals, armor stands, spectators, creative players, and players protected by team/PVP rules cannot be locked or guided into.
5. Stop aiming, switch weapons, reload, open a menu, hide the HUD, use third person, disconnect, and reconnect. Expect no stale overlay, no unrelated weapon behavior changes, and a fresh lock after re-aiming. Test small and large GUI scales and a scoped FOV; the marker must remain aligned with the target.
6. Repeat with two clients on a dedicated server: only the shooter sees their lock; both clients see guided bullets. Verify the marker and the bullet use the same server-selected target. Repeat without GenshinCraft, and launch without TACZ: optional integration must not prevent loading.
